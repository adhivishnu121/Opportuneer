# Opportuneer – Job Posting and Application Platform

**Opportuneer** is a full-stack web application developed for managing job opportunities, employer postings, and applicant interactions.  
The project focuses on **backend and frontend integration**, with a clean architecture, business logic, and database management.

---

## 📌 Project Overview

Opportuneer allows employers to post jobs, track applications, and manage candidate interactions, while enabling applicants to view, save, and apply for opportunities.  
The system supports **job management, application tracking, user authentication, and email notifications**, providing a realistic simulation of a modern job platform.

---

## 🎯 Features

- **Employer functionality**:
  - Post, update, and delete job listings
  - View applicants and their details
  - Search and filter jobs
- **Applicant functionality**:
  - Browse jobs by category, company, or role
  - Save favorite jobs and track applications
  - Apply for jobs using email as identifier
- **Backend logic**:
  - Spring Boot REST APIs for all functionalities
  - Database management with **MySQL**
  - Validation of job postings and application rules
  - Email notifications for application updates
- **Frontend**:
  - ReactJS SPA for interactive user interface
  - Responsive design for job listing and application pages
  - Integration with backend APIs using Axios
- **Testing**:
  - Backend validated using **JUnit tests**
  - Ensures API correctness and data integrity
- **Architecture**:
  - Layered architecture separating controllers, services, and repositories
  - Iterative development approach for feature integration

---

## 🛠️ Technologies Used

- **Backend:** Java, Spring Boot, JPA/Hibernate, MySQL  
- **Frontend:** ReactJS, Axios, HTML, CSS, JavaScript  
- **Testing:** JUnit  
- **Tools:** Maven, Git, GitHub  

---

## 🧠 Design & Architecture

- Object-Oriented Programming (OOP) principles used throughout backend  
- Separation of concerns: Controllers, Services, Repositories  
- Iterative development approach for gradual feature integration  
- In-memory caching for faster response on frequently accessed data  
- RESTful API design for all CRUD operations
